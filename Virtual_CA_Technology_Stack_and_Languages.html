☕ Java Backend Engine
backend/.../DoubleEntryEngineService.java
backend/.../GstCalculationService.java

Enforces zero-drift accounting logic, atomic double-entry balance, and statutory Indian GST calculations.

  • Type: Java 17/21 LTS + Spring Boot 3.x
  • Strict Math: BigDecimal with RoundingMode.HALF_UP eliminates float rounding issues.
  • ACID Safety: @Transactional(isolation = Isolation.SERIALIZABLE) guarantees ledger integrity.
  • Modern Constructs: Immutable Records (JournalLine, GstBreakup) and Enums.
🗄️ SQL (PostgreSQL) Persistence Layer
database/schema.sql

Production relational schema modeling multi-tenant accounts, immutable vouchers, invoices, and compliance.

  • Precision: NUMERIC(15,2) for exact Indian Rupee and Paisa representation.
  • Integrity: Check constraints (entry_type IN ('DEBIT', 'CREDIT')) and foreign keys with cascade.
  • Multi-Tenancy: Organization-scoped compound unique keys (UNIQUE(org_id, account_code)).
  • Statutory Schema: Dedicated compliance events and AI financial insight anomaly tables.
⚡ JavaScript (ES6+) Reactive Client
frontend/index.html (Client Script)

Powers client-side business logic, dynamic GST recalculations, and real-time double-entry journal preview.

  • Instant Feedback: In-memory double-entry balancing updates without waiting for network roundtrips.
  • Dynamic Tax Rules: Reactive Place of Supply comparison auto-switches CGST+SGST to IGST.
  • Financial Statements: Live balance sheet and P&L aggregation on voucher postings.
  • Zero Build Step: Native ES6+ runs seamlessly in all browsers with no bundler overhead.
